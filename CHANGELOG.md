# Changelog

All notable changes to the portal are written here. The site is not versioned; this log records what changed and
when.

## 2026-11-15

- Refreshed every page so a newcomer can see what Kokeb Labs is: the home page, a projects page with every public
  repository and its role, the 22 public drivers with chip and bus, the roadmap as it really stands, and the
  contributing page with the driver request flow.
- How we build now covers the safety-critical process: MISRA C++:2023, independent review, fuzzing, mutation testing,
  coverage gates, release candidates, assurance levels, IEC 62304 use, hardware validation levels H0 to H2 and the
  language standard policy.
- New figures from the ci-tools 1.22.0 figure kit: system map, process pipeline, assurance matrix, hardware levels,
  request flow and a driver call sequence.

## 2026-11-10

- The chip drivers live in the [kokeb-labs-drivers](https://github.com/kokeb-labs-drivers) organisation; the
  home, projects and roadmap pages say so and link it.

## 2026-11-06

- Rewrote every page around concrete facts: why the drivers are different, a real port and driver example, what
  is available today and what is next, where to start for each kind of visitor, the build rules, a roadmap with
  status, and good first contributions.
- The figure index is linked from the figure, not from the tabs.

## 2026-11-05

- First version: home, projects, how we build, roadmap, contributing and the "From your firmware to the chip"
  figure.
